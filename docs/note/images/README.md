撮り方の手順:

1. Unity（6000.3.15f1）で `UnityProject/BigBonusBlitz` を開く
2. 再生して、上の画面まで進める
3. Game ビューを 960×540 以上でスクリーンショット
4. `docs/note/images/` に上の名前で置く
5. 記事に1行足す（書式は下）

**11 と 16 の2枚だけでも記事の説得力がかなり変わる。** 他は後回しでいい。

## 3. 記事への足しかた

記事本体では、この書式で置いてある。

```markdown
![キャプション](images/06-timeline.png)
*キャプション*
```

## 4. note に貼るとき

note は相対パスの画像を読まない。手順は次のとおり。

1. note のエディタで、`![...](images/...)` の行の位置に画像を1枚ずつアップロードする
2. アップロードしたら `![...](...)` の行は消す
3. 直下の `*キャプション*` の行は残す（note のキャプション欄に入れてもよい）

見出し画像（サムネイル）は未作成。`06-timeline.png` か `04-hero-9poses.png` が候補。

## 5. 作り直すとき

図解の文言・色を変えたいときは `docs/note/build_images.py` を編集して再実行する。
`W`（幅）、`BG` / `INK` / `BAD` / `GOOD`（色）、各関数の文字列がまとまっている。
フォントは `C:\Windows\Fonts\BIZ-UDGothic*.ttc` を使っている。他PCで無ければ差し替える。
