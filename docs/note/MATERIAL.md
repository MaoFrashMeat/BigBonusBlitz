## 追記の書式

新しいものを「未整理の材料」の**先頭**に足す。1件3行で足りる。

```
### YYYY-MM-DD [種別] 一言で
- 何が起きたか:
- なぜ起きたか / どう直したか:
- 記事のどこに使えそうか:
```

種別は次の5つから選ぶ。

| 種別 | 中身 | 記事の行き先 |
|---|---|---|
| `失敗` | 壊れた・間違えた・やり直した | 6. 壊れた箇所カタログ |
| `仕組み` | AIの使い方で効いた・効かなかった工夫 | 3〜5. 仕組み①②③ / 11. 効かなかったこと |
| `数字` | 測って出た値 | 各所 + 付録の出どころ表 |
| `決定` | 本人が決めたこと。理由も | 9. 今も直っていないもの / 各所 |
| `絵と音` | 素材まわり | 8. 絵と音をどうしたか |

**数字を書くときは、必ず出どころを添える。**
「誰が測ったか」が言えない数字は記事に入れない（記事中の失敗⑩がその事故）。
