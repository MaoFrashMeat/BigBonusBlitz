# BigBonusBlitz モーション効果音

Unity本体へ21種類の追加効果音と再生処理を反映しました。追加素材がなくても実行時の合成音で再生できます。

## 対応表

| Cue | 音 | タイミング |
|---|---|---|
| hover | 選択への反応 | マウスでボタンへ移動・方向キー・Tab |
| click | 決定 | ボタン操作。固有音がある操作では重ねない |
| open | 画面を開く | ショップ・装備・設定・確認画面の表示 |
| close | 閉じる | 閉じる・キャンセル・戻る |
| page | ページ移動 | カテゴリ・タブ・一覧・マップのドラッグ開始 |
| toggle | 切り替え | 字幕・表示・BGMのON/OFF |
| slider | スライダー | 選択中の音量・字幕サイズの変更 |
| purchase | 購入成功 | 実際に購入・強化が成立した時 |
| equip | 装備する | 装備操作の完了 |
| unequip | 装備を外す | 解除操作の完了 |
| sell | 売却 | 売却とソウル受け取り |
| recover | 補給・回復 | 補給の購入。既存音のない回復系演出 |
| denied | 操作不成立 | 確認後に条件が変わり購入できなかった場合 |
| travel | 移動 | タイトルから開始・冒険へ出発・帰還・登退場の補助 |
| reveal | 発見・カットイン | マップの地点選択・見出し演出・カットインの補助 |
| victory | 章クリア | 新しい章クリア結果画面の表示 |
| guard | ガード | ガードの青いフラッシュ |
| impact | 衝撃 | 揺れ・被弾・撃破等。直前の戦闘音がない場合の補助 |
| cloth | 衣擦れ | タイトルの髪・リボン・衣装の揺れに低音量で添える |
| sword | 剣・金具 | タイトルの剣のモーションに低音量の金属音 |
| dialogue | 会話表示 | 会話パネルの表示。文字ごとの連打はしない |

## 再生方針

- 新旧共通ボタン部品へ接続。購入や戦闘などの固有音が鳴った操作では、汎用の決定音を追加しません。
- 効果音のない登場・被弾・カットイン等を補完。直前90ms以内に操作・戦闘音がある場合は補助音を抑えます。
- 新しい効果音は最大8ボイス。混雑時は装飾音から省略し、重要な操作音を優先します。既存の戦闘・BGM用の再生系統は維持しています。
- 選択・スクロール音は120ms、通常音は65ms、衣擦れ・剣の待機音は2.8秒の最小間隔を設定。タイトルの実際の呼び出しはさらに低頻度です。
- タイトルの待機音はモデルのモーション時刻に連動。演出抑制・モデル停止では発音せず、目の瞬きや各毛束に個別連打をしません。
- 全追加音はSE音量に従い、音量変更は再生中のボイスにも反映。SEを0にするとミュートします。
- UI再構築・自動フォーカスだけでは操作音を出しません。画面表示音は実際に有効になった後で鳴らします。

## 検証

隔離したUnity 6000.3.15f1プロジェクトで、21音の非無音・有限値・波形の余裕・両端のフェード・再現性、連打制限、ミュート、音量反映、購入時の二重音防止、戦闘音優先を自動検証しました。5画面の実描画（1280×720 / 2556×1179）と取引・操作の回帰検証も実行しています。検証エントリは `Assets/Editor/MotionSoundValidation.cs` の `Run` です。`/work/shop-qa/` の隔離コピーでのみ実行できます。`MOTION_SOUND_OUTPUT` と `ATELIER_UI_OUTPUT` に出力先を指定し、コピー側のSaveData書き込みを無効化してから実行してください。

ユーザーのセーブデータは検証に使用していません。スピーカーやスマートフォン実機での聴感・遅延の確認は未実施です。配布ビルドは作成していません。

## 素材の差し替えと追加

`MotionSoundSynth` が独自の波形を生成し、`AudioManager` が起動時に一度キャッシュします。`Resources/Audio/SE/se_motion_<cue>.wav` など同名のAudioClipを置くと素材を優先します（例 `se_motion_equip.wav`）。試聴用のWAVは生成波形の書き出しです。

新しいモーションは開始・接触・着地・完了のうち意味のある節目に `AudioManager.Create().Motion(MotionCue.X)` を1回置きます。既存演出への補助には `MotionIfQuiet` を使います。Updateや頂点ごとに発音しないでください。共通UI部品を使うボタンは自動的に操作音を持ちます。取引の成功音は成功が確定したコールバック内に置きます。

## 追加仕上げ

- 斬撃線・衝撃波・吸収・カットインにも補助音を接続。
- 補助音をLateUpdateで確定し、同じフレームで後から鳴る戦闘音も優先。同時に出る複数エフェクトは、衝撃を優先して1音にまとめます。
- 字幕非表示中は、会話パネルの表示音を出しません。
- タイトルの剣・金具の待機音は、シェーダーの呼吸モーション周期に合わせました。
- 戦闘音がエフェクトより先／後の両順序、複数エフェクトの同時発生、次フレームでの重複再生防止を検証対象に追加。
