# ショップで売る装備 50 点（2026-09-21。実装済み: game_config.json の craft）

本人の決定（案C + 案A' の混合。devlog 参照）: 店は工房。図面をソウルと素材で作る。作った品は恒久で＋ボーナス（接辞）は付かない。拾った装備には付くことがあり、帰還で流れる。

前提:

- 作った装備は **恒久**。鞄の数に入らず、売れない。街の装備画面でいつでも着け替えられる
- 素材 4 種: 鉄鉱（敵 35% / 狩猟 25% / 宝箱 30%）、獣の革（敵 25% / 狩猟 45%）、魔石（宝箱 50% / ボス 60%）、竜の鱗（ボス 100%）。財布に恒久で貯まる
- 素材の要求: 武器・手 = 鉄鉱寄り、体・足 = 革寄り、頭・アクセ = 魔石寄り。段 I 2 個 / II 4+1 / III 7+3 / IV 10+5 と竜の鱗 2
- 拾い物（潜行ごとに流れる）より **一段弱いが確実**。深さ 2〜5 のコモン〜レア相当。拾い物が上回れば潜行中は拾い物を着ける
- 部位は今の 8 枠（頭 / 体 / 手 / 足 / 武器 / アクセ ×3）。店売りは各部位 1 つずつ着ける
- 段（I〜IV）は章の踏破で解放。値段はソウル。同じ段の中で効果の種類を選ばせる（「今の自分に足りないもの」を買う）
- ★ は新しい効果キー（要実装）。無印は既にある効果キーで動く

値の目安（拾い物と比べて）: 段 I = コモン深さ 2、段 II = アンコモン深さ 3、段 III = レア深さ 4、段 IV = スーペリア深さ 5。

## 新しい効果キー（★。実装済み）

| キー | 何に効くか | 実装の場所 |
|---|---|---|
| `engageDamage` | エンゲージの攻撃ダメージ +n（全部の大きさ） | SlotMachine.StepEngage の DefeatSkillBonus と同じ所 |
| `engageLargeDamage` | 大攻撃だけ +n | 同上 |
| `engageCounterDamage` | カウンターだけ +n | 同上 |
| `lifeDamageCut` | 被弾の LIFE 減少 −n（最低 1） | 同上（Hit） |
| `chargeGuardRate` / `chargeDodgeRate` | 力を貯めたハズレの内訳（重み）に +n | EngageBattle.Resolve に cfg 以外の上乗せを渡す |
| `judgeBonus` | ジャッジ率 +n% | EngageBattle.JudgePercent |
| `potionHeal` | ルーレットの回復 +n | StepEngage（PotionHeal） |
| `potionDefeatSmall` | ルーレットの小役で討伐確定になる率 % | EngageBattle.Roulette に rng を足す |
| `engageSets` | セット数 +n | SlotMachine.EngageSets |
| `treasureRate` | 宝箱の当選率 +n%（相対） | AdventureDirector.RollTreasure の TreasureBonus |
| `replayHeal` | リプレイの回復 +nG | Evaluate の replayHealAmount |

## 値段の合計と稼ぎの目安

- 全部買うと 約 56,000 ソウル。段 I 全部（12 品）で約 1,700
- 稼ぎ: 雑魚 10 / 中ボス 60 / 狩猟 25 / 章クリア 300（ソウルの設定）。1 潜行（100〜200G）で 100〜300 ソウルが今の相場
- なので段 I は 1〜2 潜行で 1 品、段 IV は 10 潜行に 1 品。速すぎるなら値段を 1.5 倍、遅すぎるなら段 IV の解放を「3 章」→「2 章」に
