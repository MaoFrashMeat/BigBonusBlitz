## 現行本編から守る順序

`Assets/Scripts/BBB.Runtime/GameController.cs`のPlayCharacter、抽選開始、停止処理を再確認した。ベルの振り抜きは**第2停止**。第3停止だと思い込んで変更しない。停止カウントはリール番号ではなく、停止済みの個数。

| 本編の表示要求 | 接続見本 | 続きを待つ間 |
|---|---|---|
| ベル成立のBET | `attack-f1`、構えから引きへ | 最終コマを保持 |
| 第1停止 | `attack-f2`、溜め | 最終コマを保持 |
| 第2停止 | `attack-f3-4`、振り抜き | contactを一度発火してrecoverへ |
| 第3停止 | 新しい斬撃を開始しない | 進行中の復帰を続ける |
| 非ベル | walk | 歩行を継続 |
| 取消・画面切替 | CancelToLoop | 保持を解除し、遅いcontactを出さない |
