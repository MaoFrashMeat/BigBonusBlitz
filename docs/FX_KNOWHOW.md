# エフェクトのノウハウ（貯める場所）

エフェクトを作る・直すたびに、ここへ足す。調べた決まりと出典は [FX_RESEARCH.md](FX_RESEARCH.md)、見本の一覧と経緯は [FX_EFFECTS.md](FX_EFFECTS.md)。
ここには「作ってみて分かったこと」だけを書く。数値は、いつ・どの条件で効いたかと一緒に書く。

## 0. 見せる前の確認表（毎回）

- [ ] 縮小のコマ一覧だけで判断していない。**原寸で 1 コマ**見た（細い筋や炎の形は縮小で消える）
- [ ] 光っている（HDR 1 を超える）のは芯だけか。本体まで白く飛んでいないか
- [ ] 明るい背景の上で色が抜けてピンク・パステルになっていないか（加算は背景が明るいと色が消える）
- [ ] 時間: 予備 → 一撃 → 止め → 余韻 があるか。止めの間も火花・揺れは動いているか
- [ ] 隙間・継ぎ目・宙に浮いた根元がないか（炎・枠・破片）
- [ ] 同じ見本を本人に 2 回見せるなら、どこを変えたかを 1 行で言える

## 4.9 素材は取ってくる（2026-09-29）

- 本人「自分で生成しないで素材取ってきて作成して」。コードや PIL で描いた絵（扉）は品質が足りず不採用。**絵の素材は CC0 の既製品を取ってくる**のが既定
- 写実の 3D 素材（Poly Haven・ambientCG。CC0・ログイン不要）を Blender で正面から撮ると、2D の演出用の絵になる
  - 素材の .blend に入っている環境（HDRI）が見つからないとピンクになる → ワールドは作り直す
  - 格子窓などから後ろが透ける → 扉の後ろに暗い板を置く。蝶番の金具が幅に入って端が空く → 1 割内側に寄せる
- 探し方と候補の一覧は FX_EFFECTS.md の出典欄と `tools/fx-lab/textures/LICENSE-*.txt`
- 既製品が無いもの（金庫の丸扉）は Blender でモデルから作り込む（本人「モデルとディテールも作り込んで。クオリティが低い」）: 分厚い本体・面取り・同心円の溝・六角ボルト・真鍮・閂・蝶番。Cycles・AgX・デノイズ。映り込み用に上が明るい空
  - ブール演算の後に材質を足すと、空の枠が 0 番に残って白い既定の材質で描かれる → 材質を消してから入れ、面の番号を 0 に
  - 動く部品（ハンドル・閂）は別に撮る。閂は「出ている / 引っ込んだ」の 2 枚を撮って切り替える
- 金の浮き彫り（`blender/render_golddoor.py`）: AgX は明るい橙を淡いピーチに寄せる → Standard にする。環境は暗く、光は斜めからかすめる。平らな面は暗い金、面取りと稜線だけ光るのが金に見える条件
- 光の奔流（扉が開く瞬間。`LightRush`）: 背景を黒く落とさないと筋が立たない（明るい舞台の上に加算しても白くにじむだけ）。筋は細い多数＋太い少数。芯は小さく熱く、大きな白い玉にしない
  - 光は扉の奥に描く（扉より先の描画順）。手前に描くと扉が開くところが隠れる。開き方は隙間 → 一拍 → 大きく開く（0.55 秒）。一瞬で飛ばすと開いたことが見えない

## 4.10 光は式で描く（2026-09-30）

**訂正（同日）: 式だけで描かない。テクスチャを土台にする。** 本人「ちゃんとテクスチャ使ってる？」「このやりとり何回やってんの」。式のノイズは滑らかすぎて質感が無い。焼いた板を読む

### 4.10.1 プロシージャル・テクスチャを焼く（`blender/bake_textures.py` → `textures/proc_*.png`）
- 継ぎ目なしの作り: Blender の 4D ノイズ / ボロノイに `(cos u, sin u, cos v, sin v) × R / 2π` を入れる。R = 1 タイルに入る周期の数。どの方向にも繋がる
- 周期の数を間違えると全部が砂になる（最初 R をそのまま半径にして 25 周期になった）。3 / 8 / 20 周期の 3 段を RGB に詰める
- 稜線（Ridged Multifractal）は 1 を超えるので Map Range 0..2.2 で収める。そのままだと白飛び
- 6 枚: noise（FBM 3 段）/ ridge（稜線 2 段＋ハイブリッド）/ voro（セル・縁・滑らか）/ streak（横に長い FBM と稜線。極座標で読むと放射になる）/ warp（歪ませた FBM。炎・煙）/ sparks（点 3 段。火花・星・塵）
- EEVEE・Standard・2048px。一枚 0.4 秒。Unity では Repeat・Trilinear・ミップマップ・異方性 8 で読む（`LoadProc`）
### 4.10.2 板の読み方
- 「r に長い筋」は streak を `(log r, 角度)` で読む（u = log r）。奔流・光芒・星のワープ。縦の筋は `(y, x)` で読む（光の柱の鞘）
- 炎は warp の G（二重に歪ませた）を極座標の螺旋 `(角度×2.5 + log r×3.5 − t, log r×2.5 − t)` で読み、稜線の G で細い糸を重ねる
- プラズマの糸は voro の G（セルの縁）を pow 2、稜線の G を pow 3。千切れは voro の R
- 板の平均は 0.5 なので、そのまま足すと全面が白く飛ぶ。pow で平均を下げてから掛ける（奔流で一度真っ白になった）

## 4.11 動きの抑揚（2026-09-30 本人「抑揚とメリハリが全く無い。急激な動きが無い」）

- 等速の ease（0.3 秒で入って 0.5 秒で消える）で全部を繋ぐと、何が起きても同じ速さで退屈。速さの差が抑揚
- 型（`FxLab.cs` の Snap / Over / Stair / Collapse / Flick / Spike / Punch）:
  1. 溜め: 出る前に反対へ小さく動く。縮む・暗く沈む・細い糸だけ垂れる・ちらつく（0.2〜0.35 秒）
  2. 一気: 2〜3 コマで出し切る（`1 − (1 − x)^5`）。ここで白（flash）・揺れ・寄り（zoom punch）
  3. 行き過ぎて戻る: 太さや大きさを 1.5〜1.7 倍まで振って減衰する sin で戻す
  4. 止め: ヒットストップ 2〜4 コマ（`c.Freeze`）。時間が止まるので、その間だけ静止画になる
  5. 保つ: 微かな呼吸＋ときどき落ちる（Flick）・跳ねる（Spike）。コマ単位で、滑らかにしない
  6. 消える: 一気（4〜6 コマ）。消える瞬間に一度明るく跳ねてから、細い糸と余光だけ残す
- 稲妻は均一な点滅にしない。2〜3 本続けざま → 間 → また。落ちる直前に画面を沈める
- 段階のあるもの（球が育つ・陣が描かれる）は階段（Stair）。段ごとに止めと白
- ワープは「漂う → 2 コマで飛び込む → 一瞬で止まる」。速度を積分して `_T` に渡す（速度を急に変えても絵が飛ばない）

## 4.12 硬さと単調さ（2026-10-01 本人「動きが硬い。全てが単調」）

- 明るさと大きさだけを時間で変えると硬い。**形そのもの**を動かす: しなる（x を y と時間の関数でずらす）・呼吸する（太さに縦の波）・漂う（中心をリサージュで）・掃く（角度をゆっくり振る）・傾く（楕円の軸を回す）
- 周期が見えると単調。周波数の合わない sin の和（1.31 / 2.17 / 3.71）を使う（`sway`）。層ごとに位相と速さを変える
- 座標そのものを歪みの板で押す（`wobble`）と、どの形も「生き物」のようにゆらぐ。量は板の 5% 程度。多いと溶ける
- カメラは保っている間もじっとしない（`Drift`）: ゆっくり寄る（3〜5%）・傾く（±0.35°）・流れる（0.4%）。止め（ヒットストップ）の瞬間だけは揺らさない。硬さが要る稲妻は落ちている間は揺らさない
- 同じ部品でも輪ごと・線ごとに傾き・速さ・楕円の比を変える（`_Sway` を輪ごとに別の値に）

- 本人「普通に作るのやめて。プロシージャルなテクスチャをしっかり選んで」「光のエフェクトが見るに耐えない」。粒子の点・丸いぼかし絵・星の絵を重ねた光は安く見える
- `Lab/Rush`（`Shaders/LabRush.shader`）: 板 1 枚に式で描く。奔流は極座標（角度 × log 半径）の上に筋を 3 層（70 / 190 / 480 本）
  - 筋ごとに太さ（細いもの多数・太いもの少数。3 乗で偏らせる）・明るさ・速さ・破線の長さをばらす。等間隔は中心を ±0.35 本ずらして崩す
  - 破線は log 半径で長く（0.55〜0.95）、頭が明るく尾が長い。短い破線は紙吹雪に見える
  - 角度を FBM でうねらせ、低い周波数の FBM で束の明暗を付ける。一様に並ぶと安い
  - RGB で半径を 1.2% / 2.6% ずらして縁に色収差。芯は指数の光＋角度ノイズの光条＋横のアナモルフィック。白い円盤にしない
  - ノイズは値ノイズより勾配ノイズ（格子の筋が出にくい）。補間は 5 次
- 扉の奥は「白く飛んで何も見えない → 目が慣れて見えてくる」（本人 2026-09-30）。奥が見えると扉の意味が薄い。白は HDR（最初 3.5 倍）でブルームが扉の縁まで滲む
- 隙間の光（`Lab/Rush` 1）: 細く硬い白い芯 → 指数で落ちる色のにじみ。板の縁で必ず 0 に落とす（四角い縁が見える）
- `Lab/Proc`（`Shaders/LabProc.shader`）に 7 種: 光の柱（縁を FBM で揺らし、列ごとに速さの違う筋が昇る）・光芒（角度方向の FBM を太い束と細い筋の 2 段）・稲妻（FBM 2 段で折り、1/24 秒ごとに作り直す。消えている瞬間も混ぜる）・炎の渦（極座標の上で domain warp した FBM。色は黒体の並び）・光の球（フレネル＋等高線の細い糸）・衝撃波（半径を FBM で歪ませ RGB で半径をずらす）・魔法陣（距離関数の輪・六角・三角、ハッシュのルーン。別々の速さで回す）
  - 舞台に乗せるときは stageDim で舞台を落とす。加算の光は明るい舞台の上では白くにじむだけ
- 作り直しで分かったこと（本人「全部、クオリティが低い」）: 1 層の式は「形が見えるだけ」で安い。層を重ねる: 主体（芯・鞘）＋副（粒子・裂け・帯）＋環境（地面の照り返し・着地の輪・残像・画面の暗転と歪み）。それぞれ速さを変える
  - 式の粒子: 粒 i ごとにハッシュで寿命の位相・角度・速さ・大きさを決め、`age = frac(t / life + h) * life` で繰り返し出す。速度方向に伸ばす（尾は `1 + stretch * |v|`）。40 個で十分
  - 主人公の前後 2 層: 後ろの板は z +0.4（主人公の切り抜きが深度を書くので隠れる）、前は z -3.5。らせんの帯や周回する粒は `cos` の符号で前後に振り分ける
  - 炎の渦: 核を大きく明るくすると光の玉になる。閾値を上げて穴だらけにし、核は小さく（`exp(-r*14)`）。黒体の色は 0.75 倍でブルームに任せる
  - 床に寝かせた陣を主人公の前後に分けるには、板を上下半分に切って原点を縁に置く（上半分は後ろの層、下半分は前の層）
- `Color.white * x` は透明度まで下げる。不透明の絵の明るさは `new Color(x, x, x, 1)`（扉が 9 割透けていた）
  - 平らな押し出しは正面の光を返すだけで平たく見える → 放射の筋は断面を三角の稜に、炎は丸い管（ベジェ＋太さの先細り）を奥行きで潰して浮き彫りにする

## 4.14 手描き風の硬い形（2026-10-01 本人のリファレンス）

- 加算の光とぼかしでは絶対に手描き風にならない。**不透明の形**を距離関数（SDF）で作り、閾値で「白い芯 → 淡い縁 → 濃い縁 → 暗い輪郭 → 薄い外光」に塗り分ける（`Shaders/LabToon.shader`）。ブルームは掛からない（色が 1 以下）
- 打撃の閃光の形: 体（ノイズで歪んだ丸）＋棘。棘は **左右非対称の三角で両側が凹む**（pow 2〜2.6）、外へ行くほど角度がずれて**しなる**、8 本に 2 本だけ長い（長短の対比）、全体を主軸で 1.5 倍に伸ばす、小さい閃光を少しずらして重ねる（非対称）
- 失敗の記録: 均等な放射星（1 回目）→ 棘が長すぎ画面外へ（2 回目）→ 丸い星（3 回目）→ 散りで「穴」を切ったら花に見えた（4〜5 回目）→ 飛沫が中心に寄って花に見えた（6 回目）。花に見えたら、要素が中心に対称に並んでいる
- 散り: 穴を空けない。体が二乗で縮み、短い棘が先に消え、長い棘だけが細い裂片として残る。飛沫は体の外（半径の 0.75 倍より外）から出す
- コマ落とし: 5 コマごとに位相を切り替える（12fps）。位相の並び 0.05 → 0.15（最大・白・止め 4・蹴り）→ 0.3 → 0.45 → 0.6 → 0.75 → 0.9。全体 0.6 秒

## 4.15 ロゴの輝き（2026-10-03 本人の参考動画）

- 参考動画はコマに割って見る（`ffmpeg -vf fps=30`）。6 コマ連続の拡大で「毎コマ違う所が瞬く」「ロゴの面の色相が流れる」「後ろの光芒がゆっくり回る」が読める
