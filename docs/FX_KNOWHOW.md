# エフェクトのノウハウ（貯める場所）

エフェクトを作る・直すたびに、ここへ足す。調べた決まりと出典は [FX_RESEARCH.md](FX_RESEARCH.md)、見本の一覧と経緯は [FX_EFFECTS.md](FX_EFFECTS.md)。
ここには「作ってみて分かったこと」だけを書く。数値は、いつ・どの条件で効いたかと一緒に書く。

## 0. 見せる前の確認表（毎回）

- [ ] 縮小のコマ一覧だけで判断していない。**原寸で 1 コマ**見た（細い筋や炎の形は縮小で消える）
- [ ] 光っている（HDR 1 を超える）のは芯だけか。本体まで白く飛んでいないか
- [ ] 明るい背景の上で色が抜けてピンク・パステルになっていないか（加算は背景が明るいと色が消える）
- [ ] 時間: 予備 → 一撃 → 止め → 余韻 があるか。止めの間も火花・揺れは動いているか
- [ ] 隙間・継ぎ目・宙に浮いた根元がないか（炎・枠・破片）
- [ ] 同じ見本を本人に 2 回見せるなら、どこを変えたかを 1 行で言える

## 1. 光と色

| 分かったこと | 条件・数値 | 日付 |
|---|---|---|
| 全体を明るく・ブルームを強くすると白い塊になる。背景のコントラスト・彩度を上げると背景が主役を食う | 明るさ 1.7 倍・ブルーム 0.55〜1.15 で失敗 | 2026-09-26 |
| 光らせるのは細い芯だけ。本体色は 1 未満 | 芯 HDR 2.2、ブルーム閾値 1.0・強度 0.5・広がり 1/16 解像度まで | 2026-09-26 |
| 背景は一撃の間だけ暗く、少し寒色に。主役（敵・発動した本人）は沈めない | 暗転 0.55〜0.78、色抜き 0.3〜0.5、主役の効き 0.1〜0.15 | 2026-09-26 |
| 明るい背景に加算した炎はピンクになる。炎の後ろに暗い下地（乗算）を敷く | 下地 0.8〜0.85 | 2026-09-28 |
| 温度の色（暗い赤 → 赤橙 → 黄橙 → 白熱）は、明るさを曲線で締めないと全部白熱になる | 温度 = 明るさ^1.35〜1.6 | 2026-09-28 |

## 2. 形

| 分かったこと | 条件・数値 | 日付 |
|---|---|---|
| 斬撃は 3 段（白芯 / 本体色 / 暗い縁）。芯の幅は帯の 1 割 | 芯 f>0.9 | 2026-09-26 |
| 繊維の筋は、画面で 1.5〜4px にならないと見えない | テクスチャ 1024×128、線 2.5〜7px、34 本 | 2026-09-26 |
| 消すときは薄くせず削る。削れる前線を光らせると格が上がる | 前線の帯 0.07 | 2026-09-26 |
| 炎の連番を並べると隙間が出る（ランダムな位置は偏る）。本人は「枠で 1 つの炎」を選んだ | 均等な並び（黄金比）でも隙間の印象は残った | 2026-09-28 |
| 上の縁から上へ燃える炎は、根元が宙に浮いて塊に見える | 上の縁に置くなら中心向き | 2026-09-28 |
| 炎を重ねすぎると白い壁になる | 1 か所 2 枚程度 | 2026-09-28 |
| 暗い背景に暗い煙（アルファ）は見えない。部品の見本では煙の色を 0.85 まで上げる。本番は背景に合わせて決め直す | 煙 0.42 → 0.85、砂煙 0.55 → 0.95 | 2026-09-28 |

## 3. 時間

| 分かったこと | 条件・数値 | 日付 |
|---|---|---|
| ヒットストップは刃とキャラだけ止め、火花・揺れ・暗転は止めない（2 つの時計） | 連撃 3F / 弱 8F / 強 14F / とどめ 20F | 2026-09-26 |
| 敵の反応は 2F 白 → 2F 被弾色 → のけぞり | 1 未満で光らせない | 2026-09-26 |
| 炎のメラメラは、連番を実時間どおりに流すと遅く見える | 寿命の間に 64 コマ（約 3 倍速）で本人 OK 方向 | 2026-09-28 |
| 発動（バフ）は最初に山を作り、持続は控えめ | 立ち上がり 5F、山は exp(-7t) | 2026-09-26 |

## 5. 作業の進め方

- 本人の言葉が「強く」でも、明るさを上げるだけで返さない。まず調べて、決まりを数値にしてから作る（2026-09-26 に「ただ強くしただけ」と言われた）
- 1 本だけ作って原寸で見る → 直す → 全部に広げる。最初から全部を描き出さない
- 決まったこと・覆したことは `docs/devlog.md`、見本の経緯は `FX_EFFECTS.md`、ここは学びだけ
- 本人の確認はスマホのことがある。閲覧ページ（Artifact「BBB エフェクト見本帳」）に番号付きで載せる
