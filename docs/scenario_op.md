# OP シナリオ「灯の落ちた夜」（2026-09-21。実装済み: game_config.json の story.op）

最初からゲームを始めたときだけ入る、5 分ほどの序章。第 1 章「灯を継ぐ」の前に置く。
本人の骨組み（2026-09-21）: **強いボスから逃げてきてボロボロ → ステージが始まるがライフが 0 になって倒れる → 暗転の中で誰かが助ける → 街の宿屋で目覚めて「私……どうして？」→ 街を探索しながらチュートリアル**。

- 長さの目安: 台詞 58 行 × 5〜6 秒 ＝ 5 分弱 ＋ 逃走の 4 回転（結果は固定）＋ 街の探索（3 か所を回る）
- 出し方: 台詞窓はタップで送る。「飛ばす」は右上（2 周目以降は最初から飛ばせる）
- 【声】は姿のない語り手（本編と同じ）。無印は主人公。〔 〕はト書き
- 場面 1 と 2 は夜の岩場（竜の巣への道の背景を暗く）。場面 3 は黒。場面 4〜6 は街
- 「逃げてきた相手」は名前を出さない。**竜だとは言わない**（第 1 章の終点で会うので、ここでは「影」）

## 実装（2026-09-21）

- `Adv.opDone` / `Adv.opStep`（セーブ）。新しいゲームは MapScreen から即ゲーム画面 → 逃走の場面 → LIFE を `story.op.lifeSpins`（4）にして回す（毎回ハズレ）→ 0 で暗転 → `opStep="town"` で街 → 宿屋・灯守（ここで LIFE が戻る）・商店・門の台詞 → `opStep="gate"` で冒険へ → 最初の回転はベル → 門を出る台詞 → `opDone`
- 台詞窓は `OpeningPlayer`（暗幕 + 下の窓 + 飛ばす）。話者 "" = 主人公、"声"、"*" = ト書き
- 場面 2 の「敵に殴られて 0」は入れていない（4 回転ぜんぶハズレで灯が尽きる）。街の探索は台詞で 3 か所を回る形で、画面の移動はしない
- 描き出しは tools/opening-qa

## 当初の当たり（参考）

- 新しい状態 `Adv.opDone`（セーブ対象）。false で新規開始 → TAP TO START の後に OP へ
- 台詞は `game_config.json` の `story.op`（scenes → lines。話者と ト書き の種別つき）。物語タブで編集できる形に
- 場面 2 と場面 5 の門は GameController で結果を固定（`DebugForceFlag` と同じ仕組み）。場面 2 は LIFE を 4 G に仮置きして、4 回転目の被弾（`engage.lifeDamage` 3）で 0 にする。倒れたら通常の「力尽き」ではなく OP 専用の暗転へ
- 場面 3 は黒い全面パネルに台詞だけ
- 場面 4〜5 は街の画面（MapScreen）に「行ける場所を 3 つに絞る」モードを足す。商店は開くだけで買えない（ソウル 0）
- 「飛ばす」で opDone = true。設定から「序章をもう一度」
- 声: docs/voice_script.md に `op_wake`（「私……どうして？」）と `op_go`（「行く。……何があったか、見に行く」）を足す
