# 冒険画面 V2

ゲーム画面の生成時に AdventureUiV2.Apply を実行します。Unityで冒険画面へ入り直すと反映されます。

- 下部と画面外周を濃紺に統一。パネルと数値表示の重複した金枠を除去。
- V2のエンバー・ソウル・剣アイコンとBET/AUTOボタンを使用。
- 獲得数値を大型化。設定・累計G・資源を2行で整理。
- プレイヤー、ボーナス進捗、AT期待度、状態の行を分離。
- 設定・音量／収支グラフはリール下の44高ボタンへ。デバッグはDキーで引き続き利用可能。
- HOLDは錠と「進行停止」で表現。外周発光の太さを縮小。
- リールタップ、キーボード、BET、AUTO、設定・グラフの既存コールバックを保持。

画像は実際のUnity uGUIを分離したバッチプロジェクトで描画したものです。1280×720は通常時、2556×1179はREGボーナス51/90。セーブファイルは読み書きしません。

検証: AdventureUiValidation.Run、docs/check_layout.py。
