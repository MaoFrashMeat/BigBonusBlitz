# 冒険画面 V2

ゲーム画面の生成時に AdventureUiV2.Apply を実行します。Unityで冒険画面へ入り直すと反映されます。

- 下部と画面外周を濃紺に統一。パネルと数値表示の重複した金枠を除去。
- V2のエンバー・ソウル・剣アイコンとBET/AUTOボタンを使用。
- 横幅1170の舞台に、EMBER・PAYOUT・LIFEを3行で配置。設定・累計G・資源は表示器の下端へ。
- AT期待度はボーナス見出しの右へ分離し、獲得数の行を広く確保。
- 設定・音量／収支グラフは右下の44高ボタンへ。アイコンに短いラベルを併記。デバッグはDキーで引き続き利用可能。
- BET・AUTOはボタン内にキーボード／タッチの操作案内を表示。LIFEはV2のハートアイコンとフラットなゲージで統一。
- HOLDは錠と「進行停止」で表現。外周発光の太さを縮小。
- リールタップ、キーボード、BET、AUTO、設定・グラフの既存コールバックを保持。

画像は実際のUnity uGUIを分離したバッチプロジェクトで描画したものです。1280×720は通常時、2556×1179はREGボーナス51/90。セーブファイルは読み書きしません。

検証: AdventureUiValidation.Run、docs/check_layout.py。Unity上でボーナス見出し・AT期待度・獲得数、ボタンの主文と案内、ツールのアイコンと文字の矩形が重ならないことも検査します。
