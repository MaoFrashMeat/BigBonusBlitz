# Title画像のLive2D化：パーツ分け下案

parts-concept-v1.png は内蔵 image_gen による生成下案です。完成したLive2D素材ではありません。
元画像のピクセルを切り出したものではなく、顔の角度、髪、装備の形状・比率に差があります。
単一PNGであり、独立レイヤー、位置合わせ、アルファ透過の検証、PSD化、Cubismでの動作確認は未実施です。
背景の市松模様は透過と断定できません。

## 元絵に忠実な本制作で必要な分割
- 頭：顔の地肌、耳、首。前髪で隠れた額と輪郭を補完。
- 目：画面左右それぞれ、白目、虹彩、瞳孔、ハイライト、上まつ毛、下まつ毛、まぶた。
- 表情：左右の眉、口内、上唇線、下唇線、舌、必要なら歯。
- 髪：後ろ髪、左右の横髪、前髪の束、頭頂部、アホ毛。
- リボン：左右の羽、結び目、垂れ。
- 胴：首元、胸甲、腹部、腰ベルト。呼吸の変形でも硬い鎧の形を崩さない設計。
- 画面左の腕：肩当て、上腕、前腕、手袋。手を振るなら手首の隠れた部分も補完。
- 画面右の腕：肩当て、上腕、前腕、握り手。剣との前後関係を維持。
- 剣：独立パーツ。握り手や髪の裏にある刃と柄を補完。
- 下半身：青いスカート、左右の白い外套、フリル、見えている太もも、革の装具。
- 背景：キャラを除いた城と風景。揺れで露出するキャラの裏側を補完。

## 組み立て要件
Title.pngと共通のキャンバス上で各パーツを元の位置に置き、透過レイヤーで重ねたときに元絵と一致するよう確認する。
関節と髪の裏には動かした際の隙間を防ぐ描き足しを入れる。
最初の動きは瞬き、口の開閉、呼吸、髪とリボンの小さな揺れ、控えめな首傾げを想定。
本下案はこの位置合わせや描き足しの品質を保証していない。
